# HomeStack 🏠

An intuitive web application designed for families to manage their finances, track expenses, and replace manual paper-based accounting.

## Features
- **User Authentication:** Secure login and registration (In progress).
- **Transaction Tracking:** Easily log income and expenses (In progress).
- **Visual Insights:** Dynamic charts for expense distribution (In progress).
- **Multilingual Support:** English and Spanish interfaces (In progress).

## Tech Stack
- **Backend:** Python / Flask
- **Frontend:** HTML / Bootstrap 5 / JavaScript
- **Database:** SQLite

## How to run
1. Install requirements: `pip install -r requirements.txt`
2. Run the app: `flask run`
